# IT3130 Git Basics Lab

## Purpose
This repository demonstrates a basic Git workflow for IT3130.

## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation

## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push

## What I learned
This lab showed me how the working directory, staging area, and repository work together. I also practiced making commits to save my work and using a remote to connect my project to GitHub.
